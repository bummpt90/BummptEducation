**BummptEducation** is an enterprise-grade, multi-tier educational administration and telemetry management system designed and developed by **Bummptech Global Concepts**. Built to serve modern African educational ecosystems, it unifies Early Childhood (KG 1–3), Primary School (Basic 1–6), Secondary College (JSS 1–SSS 3), and central State Ministry of Education & SUBEB supervisory oversight into a single cohesive platform.

## 🚀 Key Features & Core Modules

### 1. Benue State Education Headquarters (23 LGAs Hub)
- **Statewide Institutional League Table**: Real-time performance tracking across all 23 LGAs (Makurdi, Gboko, Otukpo, Katsina-Ala, Vandeikya, etc.).
- **TRCN Faculty Biometric Compliance**: Live audits of teacher certification, lesson note submissions, and student-teacher ratios.
- **Dynamic 13-Week Term Simulator**: Predictive modeling of continuous assessment completion, attendance degradation, and revenue collection across the academic term.
- **Executive Governor & Commissioner Memos**: Automatic compilation of cabinet-level briefing documents and zonal quality assurance inspection reports.

### 2. Headquarters Live Chat & Dispatch Console
- **Two-Way School Dispatch System**: Enables Principals and Headteachers from any of the 23 LGAs to submit official updates, teacher requisition requests, facility complaints, and grant inquiries directly to Ministry representatives.
- **Simulated Role Personas**: Switch between *School Head*, *SUBEB Desk Officer*, and *Hon. Commissioner* identities.
- **Intelligent HQ Acknowledgment**: Generates official state reference numbers (`BN/HQ/...`) and assigns dispatches to relevant Zonal Inspectorates.
- **Commissioner Escalation Desk**: Direct escalation channel for urgent infrastructure emergencies and teacher deficits.
- **Export & Print**: Generates printable official dispatch transcripts for school documentation.

### 3. Specialized Educational Wings & Arms
- **Early Childhood & KG Arm (KG 1, KG 2, KG 3)**:
  - Guided by Early Years Head Mrs. Abigail Balogun.
  - Montessori phonics, early numeracy, developmental milestones, and visual behavioral reports.
- **Primary School Arm (Basic 1 to Basic 6)**:
  - Universal Basic Education curriculum under Mrs. Grace Iveren Shima.
  - Focus on STEM foundations, English diction, agricultural science, and national values.
- **Secondary College Arm (JSS 1 to SSS 3)**:
  - Supervised by Vice Principals Academic & Administration (Mr. Terver Tyokyaa / Mr. Emmanuel Agbo).
  - STEM, Humanities, and Commercial tracks preparing students for BECE, WAEC, and NECO exams.

### 4. Academic Wing & Continuous Assessment (40/60)
- **NERDC Standard Scoring Engine**:
  - **1st CA Test**: 10 Marks
  - **2nd CA Test**: 10 Marks
  - **Project / Practical Assignment**: 20 Marks
  - **Terminal Examination**: 60 Marks
  - **Total**: 100 Marks (A1 to F9 grading scale with grade points & remarks).
- **Automated Class Broadsheets**: Compiles overall class standings, subject averages, GPA computations, and ranking algorithms.
- **Official Terminal Report Card Generator**: Print-ready, high-resolution student report cards equipped with verified verification QR codes, psychomotor skills ratings, and automated affective domain evaluations.

### 5. Bursary, Accounts & Admissions Wing
- **Fee Invoicing & Payment Tracker**: Handles tuition, PTA levies, science laboratory fees, and uniform dues.
- **Digital Receipt Generator**: Generates tamper-evident receipt vouchers with verified bank transaction references.
- **Bursary Expense Ledger**: Records running operational costs, utility bills, maintenance outlays, and staff stipends.
- **Online Admission & Entrance Screening**: Manages applicant registration, entrance examination scores, and automated admission letters.

### 6. Lesson Notes Repository & Scheme of Work
- **Curated Weekly Lesson Notes**: Searchable and downloadable PDF lesson notes across all classes (KG 1 to SSS 3).
- **Subjects Included**: Mathematics, English Language, Basic Science & Technology, Physics, Chemistry, Biology, Agricultural Science, Civic Education, and Phonics.
- **Direct PDF Export**: One-click download and print functionality for parents, student study revisions, and inspectorate evaluations.

### 7. Student Leadership & Democratic Voting Council
- **Electoral Commission Engine**: Configures secret-ballot elections for school prefect positions (Head Boy/Girl, Library Prefect, Health & Sanitation Prefect, Sports Captain).
- **Candidate Manifesto Portals**: Manifestos, grade requirements, and profile pledges.
- **Real-Time Ballot Counter**: Instant cryptographic tallying with turnout analytics.

## 🔒 Security, Authentication Gateway & RBAC Architecture

- **Phase 7 Authentication Gateway**: Unauthenticated visitors are directed to the secure gateway featuring verified Login, Controlled Account Requests, and OWASP-compliant Password Recovery.
- **Controlled Sign-Up Model**: Prospective staff submit registration requests stored in `user_account_requests` with status `PENDING`. Public visitors cannot elevate themselves to privileged roles. School Principals vet and approve campus-level staff, while State Officers oversee statewide requests.
- **Argon2id & JWT Cryptography**: All passwords hashed using Argon2id (`v=19`, `m=65536`, `t=3`, `p=4`). Sessions are managed via tamper-resistant, HTTP-only JWT cookies.
- **Multi-Tenant Isolation**: Database queries strictly filter on `school_id` based on user `TenantContext`, preventing cross-school data leakages.
- **Wing Access Gatekeeper**: Secondary passkey clearance protecting high-sensitivity administrative and continuous assessment wings.

### Database Architecture (PostgreSQL Foundation)

BummptEducation utilizes an isolated, server-side PostgreSQL database layer designed for relational integrity, 40/60 continuous assessment calculations, bursary transaction records, and multi-school tenancy:

- **Database Client**: `node-postgres` (`pg`) with enterprise connection pooling (`Pool`).
- **Isolation**: The browser frontend never connects to PostgreSQL directly; all database operations are secured behind Express backend endpoints.
- **Preview & Fallback Support**: If `DATABASE_URL` is unconfigured, the application runs seamlessly in safe development/preview mode utilizing existing local state without crashing.
- **Health Diagnostics**: `GET /api/health/db` provides real-time connection status, server latency, and pool statistics without exposing credentials.
- **Migration System**: Version-controlled SQL migrations located under `src/db/migrations/` track schema evolution deterministically.

#### Environment Configuration
```env
# PostgreSQL Connection (Optional in preview mode; required for live DB persistence)
DATABASE_URL="postgresql://USER:PASSWORD@HOST:5432/DATABASE_NAME?sslmode=require"
DATABASE_POOL_SIZE="10"
DATABASE_SSL="require"
DEBUG_SQL="false"
```

## 💻 Getting Started

### Prerequisites
- Node.js 18.0 or higher
- npm 9.0 or higher (or pnpm / yarn)

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bummptech/BummptEducation.git
   cd BummptEducation
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   The application will be live at `http://localhost:3000`.

4. **Build for production:**
   ```bash
   npm run build
   ```
